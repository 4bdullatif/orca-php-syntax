## Modifications

Orca does not read TextMate grammar `injections`, which VS Code's PHP grammar relies on to find
`<?php` tags inside HTML. The build script reproduces that injection and makes these changes:

- `html.tmLanguage.json`, `html-derivative.tmLanguage.json`, `javascript.tmLanguage.json` and
  `css.tmLanguage.json`: every begin rule, and every capture with patterns, tries
  `text.html.php#php-tag` first. The HTML grammars' own `injections` (which flag a stray `<` as
  invalid) are removed.
- `php-html.tmLanguage.json`: its `injections` are removed and `#php-tag` is tried after the HTML
  rules at the top level, so `<?xml` stays an XML declaration as in VS Code.
- `xml.tmLanguage.json`: capture keys that are not numbers (`end` and `name` in the `<%--` rule) are
  removed; the engine never used them and Orca refuses them.
- All grammars: the `information_for_contributors` and `version` keys are replaced by a `comment`.

`language-configuration.json` keeps the comment markers, brackets, auto-closing and surrounding
pairs, without the `notIn`, indentation, folding, word pattern and on-enter rules Orca does not read.

This is an independent community plugin, not an official Microsoft, VS Code or Orca project.
